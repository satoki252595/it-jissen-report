### 1-1 Nous Research、コーディング／エージェント推論モデル「MISSINGNO」を公開
<callout icon="📌" color="gray_bg">
	**何が新しいか**
	Nous Research が X で、**トークン効率の高いコーディング・エージェント推論モデル「MISSINGNO」**を発表しました。Nous Portal で期間限定の無料提供となり、Hermes Agent からすぐ使えます。
</callout>
#### なぜ重要か
- エージェント処理はトークン消費が費用を左右するため、効率をうたうモデルは比較対象になります。
- ベンチマークや料金の詳細は投稿時点で公開されておらず、評価は自社タスクで行う必要があります。
#### どう使うか
1. Nous Portal にログインし、MISSINGNO を選びます。
2. 既存のコーディングタスク数件で、出力トークン数と正答率を今のモデルと比べます。
3. 無料期間が終わる前に、継続利用するか判断します。
<callout icon="💼" color="green_bg">
	**ビジネス活用例**
	- 開発チームが CI の失敗ログ要約やテスト修正案の作成に使い、1件あたりのトークン費用を既存モデルと比較する。
</callout>

### 2-1 Deno チームが Cloudflare に合流、Workers のセルフホストを強化へ
<callout icon="📌" color="gray_bg">
	**何が新しいか**
	Cloudflare が Deno の買収を発表しました。Ryan Dahl 氏と Bert Belder 氏が、Deno の celld と Cloudflare の workerd を統合し、**Workers と Durable Objects をセルフホストしやすくする**取り組みを率います。金額は公表されていません。
</callout>
#### なぜ重要か
- workerd の Durable Objects は単一インスタンス向けにとどまっていましたが、celld はオブジェクトストレージだけに依存して分散実行できます。
- 「Workers に乗ると抜け出せない」という懸念が和らぎ、Workers の採用を検討しやすくなります。
- Cloudflare 公式ブログの日付は 10/9 で、TechCrunch の報道は 10/11 01:25 JST です。
#### どう使うか
1. Workers や Durable Objects を使う既存アプリを洗い出し、セルフホストが必要な案件（規制・オンプレ）を整理します。
2. 検証環境で celld か workerd を動かし、既存の Wrangler バンドルが動くか確かめます。
3. 今後数か月の続報を待ち、本番採用は統合後に判断します。
<callout icon="💼" color="green_bg">
	**ビジネス活用例**
	- 金融や公共の SaaS 事業者が、通常は Cloudflare で動かし、データ所在の要件がある顧客だけ同じコードを自社環境で動かす。
</callout>

### 2-2 ビルド不要の SPA フレームワーク「JOPS」1.0
<callout icon="📌" color="gray_bg">
	**何が新しいか**
	ネイティブ ES Modules だけで動く小型 SPA フレームワーク JOPS（npm: `jops-core`）の紹介記事が公開されました。**コンパイラもバンドラーも不要**で、import map とモジュールスクリプトを置くだけで動きます。
</callout>
#### なぜ重要か
- ビルド環境を持たない小さな管理画面や社内ツールを、手早く作れます。
- 1.0 になったばかりでエコシステムは小さいと作者自身が書いており、大規模開発には向きません。
#### どう使うか
1. HTML に import map とスクリプトタグを追加します。
2. `./src/App.js` に画面を書き、ブラウザで開きます。
```html
<script type="importmap">
{ "imports": { "jops-core": "https://cdn.jsdelivr.net/npm/jops-core@latest/lib/jops-core.min.js" } }
</script>
<script type="module"
        src="https://cdn.jsdelivr.net/npm/jops-core@latest/lib/jops-core.min.js"
        data-app="./src/App.js"></script>
```
<callout icon="💼" color="green_bg">
	**ビジネス活用例**
	- 少人数の業務改善チームが、ビルドパイプラインなしで社内向けの入力フォームや一覧画面を作る。
</callout>

### 3-1 Cloudflare API MCP サーバーが Cloudflare Skills を配信
<callout icon="📌" color="gray_bg">
	**何が新しいか**
	Cloudflare API の MCP サーバーが、Skills over MCP 拡張を通じて Cloudflare のスキルを配信し始めました。対応クライアントは **`skills/list` でスキルを見つけ**、`skill://` から中身を読めます。
</callout>
#### なぜ重要か
- エージェントが Cloudflare の操作手順を公式のスキルから読めるため、設定ミスを減らせます。
- MCP が「ツール」だけでなく「手順書」も配る方向に広がっていることを示しています。
#### どう使うか
1. Skills over MCP 拡張に対応した MCP クライアントを用意します。
2. 次の URL をサーバーとして追加します。
```text
https://mcp.cloudflare.com/mcp
```
3. スキル一覧を取得し、Workers のデプロイなど普段の作業で使います。
<callout icon="💼" color="green_bg">
	**ビジネス活用例**
	- インフラ担当が、コーディングエージェントに公式スキルを読ませて DNS や Workers の設定変更を下書きさせ、人がレビューしてから適用する。
</callout>

### 3-2 Cloudflare Traces：プロキシ層を OpenTelemetry スパンに、料金は量課金へ
<callout icon="📌" color="gray_bg">
	**何が新しいか**
	InfoQ が、オープンベータの Cloudflare Traces を解説しました。WAF・変換・キャッシュ・ルーティング・オリジン処理が OTel スパンとして並びます。機能の提供はこの記事より前から始まっていますが、**12/1 から Workers Tracing を含めてデータ量と保存量の課金に変わる**点は要確認です。
</callout>
#### なぜ重要か
- 「どのルールで弾かれたか」「どこで時間がかかったか」をログから推測せずに見られます。
- W3C traceparent を受け渡せるため、既存の APM のトレースにつなげられます。
- 料金は有料プランで 50GB の取り込みを含み、超過分は 1GB あたり 0.25 ドルです。
#### どう使うか
1. ダッシュボードで OTLP の送信先を設定し、対象ドメインを選びます。
2. 普段のサンプリング率は1%程度に抑え、調査中のホストやデバッグヘッダーだけ Trace Rules で全件取得にします。
3. 12/1 の料金変更前に、取り込み量の見込みを計算しておきます。
<callout icon="💼" color="green_bg">
	**ビジネス活用例**
	- EC サイトの SRE が、遅いリクエストの原因を CDN・WAF・オリジンのどこにあるか切り分け、問い合わせ対応の時間を短くする。
</callout>
