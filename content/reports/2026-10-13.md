### 1-1 Noiz AI と HKUST、音も生成する世界モデル「Helix World」を公開

<callout icon="📌" color="gray_bg">
	**何が新しいか**

</callout>

#### なぜ重要か
- 多くの世界モデルは無音で、後付けの音声生成はカメラの動きを知らないため定位がずれます。

#### どう使うか
1. helixworld.org のデモで、自社素材の画像を入れて試します。
2. 研究・検証用途なら GitHub（NoizAI/HelixWorld）と Hugging Face（NoizAI/HelixWorld-preview）から取得します。
- 必要環境：データセンター級GPU（公表値はH800。一般向けGPUでの性能は未公表）

### 1-2 China Telecom、1.2Bの文書解析モデル「TeleOCR」をオープンソース化

<callout icon="📌" color="gray_bg">
	**何が新しいか**
	中国電信の XingChen AGI Lab が、デジタル文書と撮影文書を1つの枠組みで扱う約1.2Bの文書解析モデルを公開しました。表・数式・図をMarkdownやJSONに構造化し、**OmniDocBench v1.6で総合96.87の首位**とされています。
</callout>

#### なぜ重要か
- 曲がった・傾いた撮影文書でも、補正モデルを別に置かずにレイアウトを解析できます。
- 1.2Bと小さく、vLLMバックエンドで自社GPU上に置けるため、機密文書を外部APIに出さずに済みます。

#### どう使うか
1. コードを取得してインストールします。
2. ModelScope から重みを落とし、バッチ推論を回します。
```bash
git clone https://github.com/caipeng328/TeleOCR.git
cd TeleOCR
pip install -e .
pip install modelscope
modelscope download --model XingChen-AGI/TeleOCR --local_dir ./models/TeleOCR
python infer.py --image_sub_path ./in --result_save_path ./out --use_async \
  model_path="./models/TeleOCR" BACKEND="vllm-async-engine" LAYOUT_MODE="Detection"
```
- 必要環境：Python 3.10以上、CUDA対応GPU
- 撮影した歪んだ書類は `LAYOUT_MODE="Segmentation"` に切り替えます。

<callout icon="💼" color="green_bg">
	**ビジネス活用例**
	- 経理・法務部門が、紙の契約書や請求書の写真を表ごと構造化し、RAGや会計システムへの入力を自動化する。
	- 研究開発部門が、論文PDFの棒グラフから数値表を抜き出し、競合調査のデータ整理を短縮する。
</callout>

<callout icon="📌" color="gray_bg">

	Workers のランタイム更新時、処理中のリクエストや接続に与えられる猶予が**最大30秒から最大20分**に延びました。新しいリクエストは更新後のランタイムへ流れ、旧プロセスは既存の処理を流しきってから停止します。
</callout>

#### なぜ重要か

#### どう使うか
1. WebSocketクライアントに自動再接続を実装します。
2. 中断されたリクエストを安全に再試行できるよう、冪等性を確保します。
3. 状態は Durable Objects などに保存し、再起動後に復元できるようにします。

<callout icon="💼" color="green_bg">
	**ビジネス活用例**
	- 生成AIチャットを提供するSaaSが、長文回答の途中切断を減らし、問い合わせ件数と再生成コストを下げる。

### 5-1 WordPress「Bricksforge」にCVSS 10.0の未認証RCE、悪用が進行中

<callout icon="📌" color="gray_bg">
	**何が新しいか**
	Bricksforge 3.1.8.9以前に、認証なしで任意のPHPを実行できる脆弱性（CVE-2026-85097）があります。Patchstackが10月7日から悪用を観測し、63のIPからの攻撃を確認しました。**最新版4.0.1への更新**が推奨されています。
</callout>

#### なぜ重要か
- GIFとPHPを兼ねたファイルをアップロードし、フォーム送信時の `url` を `.php` にするだけで実行されます。
- `.phtml` や大文字・URLエンコードなど拡張子の回避も試されており、自動化された大量攻撃です。

#### どう使うか
1. 管理下のWordPressでBricksforgeの有無と版数を確認します。
2. 更新後、一時ディレクトリに不審なPHPがないか調べます。
```bash
wp plugin list --name=bricksforge --fields=name,version
find wp-content/uploads/bricksforge/tmp -iname '*.ph*' -ls
```
3. `/wp-json/bricksforge/v1/form_submit` への `temporaryFileUploads` を含むリクエストをログで確認します。

</callout>

### 7-1 Rustの「Hibana」、通信手順を1か所に書いて実行時に強制する

<callout icon="📌" color="gray_bg">
	**何が新しいか**
	複数の参加者がやり取りする手順を「コレオグラフィ」として1回だけ記述し、役割ごとの小さなプログラムに変換するRustのクレートです。各エンドポイントの送受信は、**手順と合わなければ実行時に失敗**します。no_std・アロケータ不要で、Rust 1.95以上が必要です。
</callout>

#### なぜ重要か
- 研究分野だったコレオグラフィ型プログラミングを、組み込みでも使える形にしています。
- 分岐のあいまいさや並列の衝突などの誤った手順は、変換時に弾かれます。
- ネットワークスタックではなく、分散全体の保証には条件があることをREADMEで明記しています。

#### どう使うか
1. リポジトリのサンプルを動かして、記述から実行までの流れを確認します。
```bash
cargo run --example ping_pong
```
2. 既存のプロトコル（例：機器とゲートウェイの認証手順）を `g::send` / `seq` / `route` で書き直して試します。
